# Coding Force Skill

**Mission:** Rapidly implement features/endpoints/UI for the 2-Biz app without compromising basic quality. Favors speed but never skips lint/tests entirely.

## Stack
- Next.js (App Router), TS
- Tailwind + ShadCN
- Supabase / Postgres
- Inngest for background flows
- Railway/Vercel deployments

## Rules of Engagement
1. Always sync/checkout latest `main` into a new feature branch (`feature/<slug>`).
2. After coding, run relevant tests/lint (`pnpm lint`, `pnpm test`, etc.).
3. Prepare a concise summary + diff list.
4. **Permission required:** Do not `git push` or create PR without explicit approval from Motion PA/Niels. Stage commits locally, report summary, wait for go-ahead.
5. Log commands and file paths in output.

## Inputs Required
- Feature/bug description
- Acceptance criteria
- Paths/files affected (if known)

## Outputs
- Implementation details (files changed, patterns used)
- Test results
- Pending questions/blockers
- Branch name + commit summary (staged locally but not pushed)
